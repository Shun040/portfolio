# 尹紫涔作品集 2026

暗色极光 + 毛玻璃 + 便当盒。中英双语。纯静态，无构建步骤，无外部依赖
（不引 CDN、不引字体、不引动画库），改完刷新就能看。

---

## 本地预览

```bash
cd ~/work/portfolio-2026
python3 -m http.server 5173
```

打开 <http://localhost:5173>

> 也可以直接双击 `index.html` 打开 —— 站点没有任何 fetch 请求，
> canvas 只用 `fillText` 画遮罩（不会触发跨源污染），`file://` 下一样能跑。
> 用本地服务器只是更贴近线上环境。

## 怎么改

| 想改什么 | 改哪里 |
|---|---|
| 项目内容（中英） | `js/data.js` |
| 界面文案、About、优势、页尾 | `js/i18n.js` |
| 颜色、字号、间距 | `css/site.css` 的 `:root` |
| 极光、玻璃、圆角 | `css/bento.css` 的 `:root` |
| 便当格大小 | HTML 里的 `--c` / `--rw` / `--mh`；项目格在 `js/case.js` 的 `SPAN` |
| 项目主色 | `js/data.js` 里每个项目的 `a` / `b` |
| 开场流体手感 | `index.html` 里 `new Field(...)` 的参数 |

**加一个项目**：往 `js/data.js` 数组里加一项，`en` 和 `zh` 两套内容都写全，
再去 `js/case.js` 的 `SPAN` 里加一个格子尺寸。便当盒和案例会自动生成。

**深链接**：`work.html#painshift` 会直接打开那个案例，可以单独发给别人。

## 尚未在浏览器里验证

这套代码是在没有浏览器的环境里写的。已通过：JavaScript 语法解析、
HTML 标签配对、CSS 配平、中英 159 组界面键完全对齐、六个项目双语字段结构一致、
26 个本地资源引用全部存在、本地服务器全部 200。

**没验证过的**：实际视觉、动效手感、流体性能、移动端真机。按这个顺序自己过一遍：

1. **开场页** —— 名字是否清晰可读，光标划过是否只搅动周围的场
2. **主页 Hero** —— 极光是否太艳（改 `.aurora i` 的 `opacity`），逐字入场是否自然
3. **个人经历便当盒** —— 玻璃厚度是否出来了，格子比例是否舒服
4. **项目便当盒** —— 骨架屏扫光有没有正常淡出，01 是否够突出
5. **点开 PainShift** —— 条形图是否生长、曼陀罗宫格悬停是否播放、
   呼吸练习跟着做两轮看数字变化
6. **点开 EmpaLens** —— 状态切换是否正确换徽章图
7. **点开 Tears** —— YouTube 缩略图是否加载，点击是否正常嵌入播放
8. **切中英文** —— 案例开着的时候切，看是否原地重建
9. **缩到手机宽度** —— 便当盒是否正确塌成单列
